# Java 核心规则

> 本文件包含对 P3C《Java 开发手册（黄山版）》内容的选取和改编，并补充了适用条件与示例；详见[第三方来源说明](../../THIRD-PARTY-NOTICES.md)。

规则编号用于 Java 代码 Review、回归验证和项目例外记录；具体 API 选择仍服从项目 Java 版本和已有契约。

## JAVA-001 相等性与哈希契约

级别：MUST
适用：值对象、集合元素、缓存 Key 和包装类型比较。

规则：`equals` 与 `hashCode` 成对实现；包装类型比较使用 `Objects.equals`，不要用 `==`。

正例：值对象覆盖两个方法，比较可空包装类型时使用 `Objects.equals(a, b)`。

反例：用 `==` 比较字符串或包装类型，或只重写 `equals` 不重写 `hashCode`。

例外：明确比较对象身份的场景可以使用 `==`，但不能把它当作值相等。

## JAVA-002 金额与十进制计算

级别：BLOCKER
适用：金额、税率、计费、库存价格和需要精确舍入的十进制业务。

规则：使用 `BigDecimal` 或项目约定的最小货币单位；避免 `double` 直接计算和比较，并明确舍入模式和精度。

正例：从字符串构造 `BigDecimal`，在边界统一设置 scale 和 rounding mode。

反例：用 `double` 累加金额，或使用 `new BigDecimal(double)` 引入二进制误差。

例外：仅用于展示近似值且不参与业务决策的数值可以采用浮点类型，但应明确标注。

## JAVA-003 时间与时区

级别：MUST
适用：时间存储、格式化、跨时区接口和定时任务。

规则：时间优先使用 `java.time`，明确时区；共享格式器使用不可变的 `DateTimeFormatter`。

正例：存储 UTC 或带偏移的时间，在接口边界按约定时区格式化。

反例：共享 `SimpleDateFormat` 或使用无时区的字符串猜测时间含义。

例外：对接遗留协议时可以在边界转换 `Date`，但内部处理应尽快转为 `java.time`。

## JAVA-004 空值、资源与状态释放

级别：MUST
适用：集合返回值、文件/连接/锁和临时状态。

规则：不返回 `null` 集合；资源、锁和临时状态必须在所有路径释放；不要吞掉异常。

正例：返回空集合或明确的 Optional 结果，使用 try-with-resources 和 finally 释放锁。

反例：调用方必须判空的集合，或异常路径遗留连接、锁和临时文件。

例外：已有公共 API 明确约定返回 null 时，新增代码应保持兼容并在边界转换。

## JAVA-005 命名、集合与可变状态

级别：SHOULD
适用：公共 API、业务对象、并发代码和长期维护的 Java 类。

规则：用有业务含义的名称和具名常量替代魔法数字；选择与访问模式匹配的集合；共享可变状态必须有明确线程安全策略；`Optional` 主要用于返回值，不用于实体字段、序列化 DTO 或方法参数，除非项目已有约定。

正例：使用不可变值对象和具名状态枚举，按读写特征选择集合。

反例：用 `flag`、魔法数字和共享 `HashMap` 表示复杂业务状态。

例外：性能基准或框架约束可以采用可变对象，但应说明边界和并发策略。

## 常见风险

`SimpleDateFormat` 共享、字符串 `==`、循环内字符串 `+`、裸建线程、空 `catch`、用 `HashMap` 作为跨线程共享状态。
