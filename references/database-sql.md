# 数据库与 SQL

规则编号用于 Review 和迁移例外记录；ORM 语法以项目实际框架为准。

## DB-001 参数绑定与标识符白名单

级别：BLOCKER
适用：查询条件、排序、表名、列名和其他由外部输入影响的 SQL 片段。

规则：SQL 使用参数绑定；禁止把用户输入拼接到 SQL、排序片段或表名中。动态标识符只能通过固定映射白名单选择。

正例：`WHERE name = #{name}`，并将 `sort=createdAt` 映射为固定的 `created_at`。

反例：`"... name = '" + name + "' ORDER BY " + sort`。

例外：不存在可接受的“内部输入自动可信”例外；应在边界完成校验和映射。

## DB-002 写操作条件与批量边界

级别：BLOCKER
适用：UPDATE、DELETE、批量写入和大集合处理。

规则：更新和删除必须有明确条件；批量操作要考虑事务、锁、分批和最大输入，避免一次载入无法估算的大集合。

正例：按主键或租户条件更新，批量任务使用固定批次并记录失败项。

反例：拼接可为空的 WHERE 条件，或把用户提交的无限列表一次性写入数据库。

例外：全表维护任务必须有独立审批、备份和可回滚方案。

## DB-003 索引与执行计划

级别：MUST
适用：新增查询、过滤、排序、连接和高频列表接口。

规则：根据真实过滤、排序和连接条件设计索引，并用执行计划和代表性数据验证；不要仅凭字段数量猜索引是否有效。

正例：用 `EXPLAIN` 验证联合索引的选择性和扫描范围。

反例：为每个字段都建索引，或只看 SQL 文本不看执行计划。

例外：低频小表可接受简单方案，但应以数据规模和基准为依据。

## DB-004 分页、N+1 与迁移

级别：MUST
适用：分页、列表、导出、关联查询和数据库结构变更。

规则：分页、列表和导出明确上限；深分页评估游标/范围分页；避免循环内逐条查询；迁移采用可回滚或前向兼容步骤并评估在线变更影响。

正例：列表接口限制 `size`，关联数据批量查询，迁移先加兼容字段再切换读写。

反例：无限制导出、循环中执行查询，或直接删除线上仍在读取的列。

例外：一次性离线脚本可采用不同批量策略，但要说明数据量、锁影响和失败恢复方式。

ORM 语法以项目实际框架为准；MyBatis 的 `#{}`、JPA 参数绑定等是实现方式，不是跨框架的唯一写法。
