# 后端安全

规则编号用于 Review、验证和例外记录；`BLOCKER` 只表示在适用条件成立时必须阻断发布。

## SEC-001 不信任客户端身份字段

级别：BLOCKER
适用：需要登录的资源读取、修改、删除、导出和租户数据访问。

规则：请求体、查询或路径中的 `userId`/`tenantId` 只能表达目标资源，不能证明操作者身份或权限；操作者来自可信认证上下文，服务端校验资源归属和租户边界。管理员代办、批处理和服务账号必须校验显式授权范围并记录审计信息。

正例：`actorId = securityContext.currentUserId()`，再以 `actorId + resourceId + tenantId` 做权限查询。

反例：`userService.update(request.getUserId(), request)`，或只依赖前端隐藏按钮。

例外：离线批处理、管理员代办或服务间调用可以使用独立服务身份，但必须限制权限、明确代办范围并记录审计信息；不能把普通客户端参数直接升级为可信身份。

## SEC-002 凭据与敏感信息保护

级别：BLOCKER
适用：密码、密钥、Token、身份证号、支付信息和其他可用于认证或识别个人的数据。

规则：密码使用经过验证的密码哈希算法；密钥和 Token 不写入仓库、日志或异常消息；敏感字段按最小暴露原则返回并脱敏。

正例：通过环境变量或密钥管理注入凭据，日志只记录脱敏后的标识。

反例：把 API Key 写入配置文件提交，或把完整 Token 放进异常消息。

例外：受控的本地测试凭据应使用测试配置并确保不会提交或进入共享日志。

## SEC-003 外部输入与危险操作

级别：BLOCKER
适用：SQL、命令、URL、文件路径、反序列化和文件上传等由外部输入影响的操作。

规则：防 SQL 注入、命令注入、SSRF、路径穿越、反序列化和不安全文件上传；采用参数绑定、白名单、大小限制、类型校验和安全协议限制。

正例：SQL 值绑定、标识符固定映射；SSRF 校验目标地址和重定向并限制内网访问；上传校验大小与实际内容，使用服务端生成的文件名写入不可执行的隔离目录，不能仅信任客户端 MIME。

反例：直接拼接 SQL/命令/URL，或把用户提供的文件名拼接为服务器路径。

例外：内部受控输入也应沿用同一边界；只有经过明确威胁建模才能放宽限制。

## SEC-004 副作用操作的授权覆盖

级别：MUST
适用：新增、修改、删除、导出、批量操作和管理接口。

规则：权限校验覆盖所有副作用操作；认证、授权、限流和审计日志与业务逻辑分层，但必须在服务端实际执行。

正例：在应用服务入口统一校验权限，拒绝时返回稳定错误码并记录必要审计字段。

反例：只在前端隐藏按钮，或只保护查询接口而遗漏导出接口。

例外：公开只读接口不需要登录授权，但仍需评估限流和数据最小暴露。
